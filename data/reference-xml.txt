NOM
     haplo-dialog-xml - syntaxe XML des dialogues haplo-dialog

DESCRIPTION
     haplo-dialog lit une description d'interface graphique écrite dans un
     dialecte XML et affiche la fenêtre correspondante.

     DEUX PORTS lisent cette syntaxe :

          gtk3sermo(1)  port GTK 3, port de référence. Également accessible
                        sous le nom gtkdialog(1), via le paquet gtksermo.

          gtk4sermo(1)  port GTK 4. Même syntaxe, plus quatre widgets qui
                        n'existent qu'ici : <flowbox>, <overlay>, <revealer>
                        et <stack>.

     Sauf mention contraire, tout ce qui suit vaut pour les deux ports.

     La syntaxe est héritée de gtkdialog 0.8.3 (László Pere, 2003-2013).


STRUCTURE GÉNÉRALE
         <window title="Titre" width-request="400" height-request="200">
           <vbox>
             <text><label>Bonjour !</label></text>
             <entry><variable>MON_CHAMP</variable></entry>
             <button ok></button>
           </vbox>
         </window>

     Chaque dialogue doit avoir un unique élément racine <window>.  Les  widgets
     sont imbriqués dans des conteneurs (<hbox>, <vbox>, <frame>, etc.).


ATTRIBUTS COMMUNS
     Les attributs suivants sont disponibles sur la plupart des widgets :


     width-request=N
            Largeur minimale en pixels.

     height-request=N
            Hauteur minimale en pixels.

     visible=true|false
            Visibilité initiale du widget (défaut : true).

     sensitive=true|false
            Interactivité du widget (défaut : true).

     tooltip-text=texte
            Infobulle affichée au survol.


SOUS-ÉLÉMENTS COMMUNS
     <label>texte</label>
            Texte affiché ou étiquette du widget.

     <variable>NOM</variable>
            Nom de la variable d'environnement exportée à la fermeture.

     <action>commande</action>
            Commande shell exécutée via safe_system() lors d'un événement (clic,
            changement...).

     <input>commande</input>
            Commande shell dont la sortie alimente le widget.

     <default>valeur</default>
            Valeur initiale du widget.

     <item>texte</item>
            Une entrée d'une liste : <combobox>, <comboboxtext>,
            <comboboxentry>, <list>. Répéter la balise pour chaque entrée.

     <output>NOM</output>
            Destination de la valeur, en plus de la variable d'environnement.

     <output file="chemin">
            Écrit la valeur dans un fichier. ⚠ Le fichier est TRONQUÉ à
            l'ouverture : si le widget ne rend rien, le contenu précédent est
            perdu. C'est ce qui arrivait à <filechooser> dans le port GTK 4
            avant la version 1.1.2.

     <width>N</width> et <height>N</height>
            Taille en pixels, forme sous-élément des attributs width-request
            et height-request.

     <radio>...</radio>
            Synonyme exact de <radiobutton>, hérité de gtkdialog.

     <separator/>
            Synonyme exact de <menuitemseparator>, hérité de gtkdialog.


WIDGETS —— RÉFÉRENCE COMPLÈTE
   Fenêtre principale
     <window>
            Fenêtre principale du dialogue.
            Attributs  :  title, width-request, height-request, resizable, icon-
            name, decorated.


   Conteneurs
     <hbox>
            Conteneur horizontal. Enfants alignés de gauche à droite.
            Attributs : spacing, homogeneous.

     <vbox>
            Conteneur vertical. Enfants alignés de haut en bas.

     <frame>
            Conteneur avec bordure et titre optionnel.
            Sous-éléments : <label> pour le titre.

     <notebook>
            Onglets. Chaque enfant direct est une page.
            Sous-éléments : <label> pour le titre de chaque onglet.

     <expander>
            Section repliable/dépliable.
            Sous-éléments : <label> pour le titre.

     <aspectframe>
            Conteneur maintenant le ratio largeur/hauteur de son enfant.
            Attributs : ratio (ex: 1.333), obey-child.


     <eventbox>
            Conteneur invisible qui capte les événements de souris pour un
            enfant qui n'en reçoit pas lui-même.

     <flowbox>                                      [port GTK 4 uniquement]
            Grille flexible qui redistribue ses enfants selon la largeur.
            Attributs : column-spacing, row-spacing, min-children-per-line,
            max-children-per-line, selection-mode.

     <overlay>                                      [port GTK 4 uniquement]
            Superpose des widgets par-dessus un enfant principal. Le premier
            enfant est le fond, les suivants sont posés dessus.

     <revealer>                                     [port GTK 4 uniquement]
            Affiche ou cache son enfant avec une animation.
            Attributs : reveal, transition, duration.

     <stack>                                        [port GTK 4 uniquement]
            Conteneur multi-pages : une seule page visible à la fois, avec
            transition animée.
            Attributs : transition.

   Boutons et contrôles booléens
     <button>
            Bouton cliquable.
            Formes courtes : <button ok> <button cancel> <button help>
            Attributs : stock (icône GTK).

     <checkbox>
            Case à cocher. Exporte true ou false.

     <radiobutton>
            Bouton radio. Groupe via <variable> commune.

     <togglebutton>
            Bouton avec état enfoncé/relâché.

     <switch>
            Interrupteur on/off style mobile. Exporte true ou false.


     <linkbutton>
            Bouton qui ouvre une URL dans le navigateur par défaut.
            Sous-éléments : <label> pour le texte, <input> pour l'URI.

   Saisie de texte
     <entry>
            Champ de saisie mono-ligne.
            Attributs : max-length, editable.

     <password>
            Champ de saisie masqué (●●●●). Identique à <entry> en comportement.

     <searchentry>
            Champ de recherche avec icône loupe intégrée.

     <edit>
            Zone de texte multi-lignes (éditeur).
            Attributs : editable, wrap-mode.


   Affichage de texte
     <text>
            Étiquette texte statique.
            Sous-éléments : <label>, <input> pour texte dynamique.

     <statusbar>
            Barre d'état en bas de fenêtre.

     <infobar>
            Bandeau d'information coloré (info/warning/error).
            Attributs : message-type (info|warning|error|question).


   Listes et sélection
     <combobox>
            Liste déroulante avec saisie libre possible.
            Sous-éléments : <item> pour chaque entrée.

     <comboboxtext>
            Liste déroulante texte seulement (plus simple).
            Sous-éléments : <item>texte</item>.

     <list>
            Liste à défilement, sélection simple ou multiple.
            Sous-éléments : <item>, <column-header>.

     <tree>
            Arbre hiérarchique.
            Sous-éléments : <item> (format Parent/Enfant).

     <table>
            Grille de données tabulaires multi-colonnes.
            Sous-éléments : <column-header>, <item>.


     <comboboxentry>
            Liste déroulante dont le champ est ÉDITABLE : l'utilisateur peut
            saisir une valeur absente de la liste. Nom hérité de gtkdialog.

   Valeurs numériques
     <hscale>
            Glissière horizontale.
            Attributs : value, min, max, step.

     <vscale>
            Glissière verticale.

     <spinbutton>
            Sélecteur numérique avec boutons +/-.
            Attributs : value, min, max, step, digits.

     <levelbar>
            Barre de niveau (lecture seule).
            Attributs : value, min, max, mode (continuous|discrete).


   Progression et animation
     <progressbar>
            Barre de progression.
            Attributs : value (0.0-1.0), text.

     <spinner>
            Indicateur d'activité animé (roue de chargement).
            Attributs : active (true|false).


     <pulse>
            Barre de progression en mode indéterminé : elle bat sans connaître
            l'avancement. Pour une progression chiffrée, voir <progressbar>.
            Attributs : text, show-text.

   Date et heure
     <calendar>
            Sélecteur de date graphique.
            Exporte : VAR_DAY, VAR_MONTH, VAR_YEAR.


   Médias et dessin
     <pixmap>
            Affichage d'image.
            Sous-éléments : <filename>.

     <drawingarea>
            Zone de dessin personnalisée.

     <colorbutton>
            Sélecteur de couleur.
            Exporte une couleur au format #RRGGBB.

     <fontbutton>
            Sélecteur de police.
            Exporte le nom de la police sélectionnée.


     <image>
            Image affichée depuis un fichier ou depuis le thème d'icônes.
            Attributs : file, icon-name, icon-size, width, height.
            Contrairement à <pixmap>, accepte une taille explicite.

   Menus et navigation
     <menubar>
            Barre de menus principale.
            Sous-éléments : <menu> puis <menuitem>.

     <menuitem>
            Entrée de menu.
            Attributs : label, stock, accel.


     <menu>
            Menu déroulant d'un <menubar>. Contient des <menuitem> et des
            <menuitemseparator>.
            Sous-éléments : <label> pour le titre du menu.

     <menuitemseparator>
            Ligne de séparation entre deux entrées d'un <menu>.

   Terminal et séparateurs
     <terminal>
            Terminal interactif embarqué.
            Sous-éléments : <input> pour commande initiale.

     <hseparator>
            Séparateur horizontal.

     <vseparator>
            Séparateur vertical.


     <gvim>
            Embarque une fenêtre gvim dans le dialogue, via GtkSocket.
            ⚠ Port GTK 3 uniquement. GtkSocket a été supprimé de GTK 4 : le
            port GTK 4 affiche à la place une étiquette qui le dit, et écrit un
            message sur la sortie d'erreur. Il ne fait pas semblant.

   Choix de fichier
     <filechooser>
            Bouton qui ouvre un sélecteur de fichier. La valeur exportée est le
            chemin choisi.
            Attributs : action (open, save, select-folder, create-folder).
            ⚠ Dans le port GTK 4, ce widget ne fonctionne qu'à partir de la
            version 1.1.2 : avant, c'était un bouton ordinaire qui ne
            choisissait rien et vidait le fichier de <output>.

     <chooser>
            Sélecteur de fichier hérité de gtkdialog, nettement plus limité que
            <filechooser>. Conservé pour la compatibilité des vieux scripts.
   Contrôle du flux
     <timer>
            Déclencheur temporel.
            Attributs : interval (ms), visible.
            Sous-éléments : <action> exécutée à chaque tick.


VARIABLES D'ENVIRONNEMENT
     À la fermeture du dialogue (bouton OK ou EXIT), haplo-dialog exporte chaque
     widget ayant une <variable> dans l'environnement shell :

         export MON_CHAMP="valeur saisie"
         export MA_CASE="true"
         export MON_SLIDER="0.75"

     Le script appelant récupère ces valeurs directement :

         gtk3sermo --program DIALOG_VAR
         echo "Nom saisi : $NOM"


ACTIONS SPÉCIALES
     Les <action> reconnaissent les mots-clés suivants :


     EXIT:valeur
            Ferme le dialogue et retourne valeur comme code de sortie.

     REFRESH:variable
            Rafraîchit le widget identifié par variable via sa balise <input>.

     ENABLE:variable
            Active le widget identifié par variable.

     DISABLE:variable
            Désactive le widget identifié par variable.

     SHOW:variable
            Rend visible le widget identifié par variable.

     HIDE:variable
            Cache le widget identifié par variable.

     CLEAR:variable
            Vide le contenu du widget identifié par variable.


SÉCURITÉ
     MODÈLE DE CONFIANCE
            Le script XML vient de l'auteur du dialogue, qui a déjà le droit de
            lancer des commandes. Ce n'est PAS un bac à sable : une <action> ou
            un <input> exécute ce qu'on y écrit.

     COMMENT safe_system() EXÉCUTE
            Si la commande ne contient AUCUN métacaractère shell, elle est
            lancée directement par exec(), sans shell — l'injection est alors
            impossible. Si elle en contient un seul, il y a repli sur
            /bin/sh -c, qui rend la pleine puissance du shell ET la pleine
            surface d'injection.

            Les métacaractères qui déclenchent le repli sont exactement :
                | & ; < > ( ) { } $ ` \ " ' ~ * ?

     IL N'Y A AUCUNE LISTE BLANCHE PAR DÉFAUT
            Une version antérieure de cette page affirmait que safe_system()
            « impose une liste blanche de commandes autorisées ». C'ÉTAIT FAUX.
            Le filtre existe, mais il est éteint tant qu'on ne l'allume pas :
            _allowlist_permits() lit HAPLO_ALLOWED_CMDS et, si la variable est
            absente ou vide, rend TRUE — le code dit « liste absente : aucune
            restriction ».

     LES DEUX VERROUS, À POSER SOI-MÊME
            HAPLO_ALLOWED_CMDS=cmd1,cmd2,...
                   Allume la liste blanche. Le filtre porte sur le basename de
                   argv[0]. Tant que la variable est posée, le repli
                   /bin/sh -c est REFUSÉ, pas seulement filtré.

            HAPLO_NO_SHELL_FALLBACK=1
                   Refuse le repli /bin/sh -c, sans restreindre les commandes.

     LA VALEUR D'UN WIDGET N'EST PAS DE CONFIANCE
            Elle vient de la personne qui SE SERT du dialogue. Ne jamais la
            passer à eval, ni la concaténer dans une <action>. Pour agir sur
            une valeur, la voie sûre est --do.

     Voir SECURITY.md et gtk3sermo(1) pour la politique complète.

EXEMPLE COMPLET
         #!/bin/sh
         export FORMULAIRE='
         <window title="Inscription" width-request="380" height-request="260">
           <vbox spacing="8">
             <frame><label>Vos informations</label>
               <vbox>
                 <hbox>
                   <text><label>Nom :</label></text>
                   <entry><variable>NOM</variable><default>Dupont</default></entry>
                 </hbox>
                 <hbox>
                   <text><label>Mot de passe :</label></text>
                   <password><variable>MDP</variable></password>
                 </hbox>
                 <checkbox>
                   <label>Accepter les conditions</label>
                   <variable>CGU</variable>
                 </checkbox>
               </vbox>
             </frame>
             <hbox>
               <button ok></button>
               <button cancel></button>
             </hbox>
           </vbox>
         </window>'

         gtk3sermo --program FORMULAIRE

         if [ "$CGU" = "true" ] && [ -n "$NOM" ]; then
             echo "Inscription de $NOM —— CGU acceptées"
         else
             echo "Inscription annulée ou CGU refusées"
         fi

HISTORIQUE
     haplo-dialog descend de gtkdialog(1) (László Pere, 2003-2013), corrigé et
     durci en 2026. Le port GTK 3 est arrivé le premier ; le port GTK 4 l'a
     rejoint et lit la même syntaxe.

     Cette page décrit la version 1.1.3. Les versions antérieures plantent
     quand on ferme un <infobar> ; celles antérieures à la 1.1.2 rendent une
     valeur fausse pour <checkbox> et <radiobutton> dans le port GTK 4.
